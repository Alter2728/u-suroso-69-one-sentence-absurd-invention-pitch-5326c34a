An entry for make.fun's [One-Sentence Absurd Invention Pitch](https://make.fun/bounty/u-suroso-69-one-sentence-absurd-invention-pitch-5326c34a) bounty ($2.50 in USDC): a program that writes one sentence pitching a ridiculous invention that fixes a tiny everyday annoyance.

`main.py` (Python 3.13, standard library only) writes a single sentence to `/output/entry.txt`. The pitch: a TV remote that hides itself the moment an argument about what to watch breaks out, then comes back only after everyone has agreed on a nature documentary about moss — the argument ends not by picking something good, but by mutual boredom. The output is deterministic: every run writes the same sentence, 167 characters, inside the gate's 1–220 character limit.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
